# **📈 Looker Studio**

This folder contains a **Looker Studio dashboard** for an imaginary car sales company, demonstrating data visualization and reporting skills.

## **📊 Contents**

* **Sales Performance Overview** – Track overall sales and trends

* **Traffic Sources & Campaigns** – Analyze marketing effectiveness

* **Conversion Insights** – Understand lead-to-sale performance

* **Visual Storytelling** – Metrics and charts for clear decision-making

  ## **🛠 Built With**

* **Looker Studio** – For interactive dashboards and reporting

* **Charts & Visualizations** – Bar, line, and pie charts for insights

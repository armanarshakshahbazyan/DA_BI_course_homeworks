# **📊 Power BI**

This folder contains Power BI dashboards focused on financial performance, budgeting insights, and variance analysis across regions and IT areas.

---

## **📈 Contents**

**Financial Overview** – Actual vs Budget & Forecast (Monthly \+ YTD)  
 **Regional Performance** – Spending trends and variance % across global regions  
 **Cost Element Breakdown** – Administrative, Labor, Hardware, Depreciation & more  
 **IT Area Insights** – Which departments drive overspend or savings  
 **Trend Analysis** – Running totals and budget progress visuals  
 **Interactive Features** – Buttons, filters, bookmarks, and drill-downs in the PBIX file

---

## **🛠 Built With**

**Power BI Desktop** – For interactive dashboards and data modeling  
 **DAX Measures** – Variance calculations, YTD totals, custom KPIs  
 **Visual Analytics** – Line charts, bar charts, tables, decomposition tree, KPIs
